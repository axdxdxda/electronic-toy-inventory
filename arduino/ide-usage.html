🔍 四個核心功能

每個按鈕都有它的用途，記下它們才不會搞混。

✅ 驗證（編譯）

檢查程式有沒有打錯字，不用接 Arduino 也能測

➡️ 上傳

把程式寫進 Arduino，讓它開始執行

🔍 序列監視器

即時看 Arduino 傳回來的訊息，超好除錯

📚 程式庫管理

下載別人寫好的功能，省下重新發明輪子的時間

📋 第一次寫程式：8 步驟流程

照順序做就對了 — 每步都很簡單！

1
開新檔

檔案 → 新增（或按 Ctrl+N）

2
寫程式

在中間的編輯區輸入 Arduino 程式碼

3
存檔

按 Ctrl+S，取個好記的檔名

4
選開發板

工具 → 開發板 → 選 Arduino Uno（或你用的型號）

5
選序列埠

工具 → 序列埠 → 選 COM3 之類的（看哪個有 Arduino）

6
按驗證 ✅

檢查有沒有打錯字，紅字 = 有錯，得修正

7
按上傳 ➡️

程式燒進 Arduino，等 5-10 秒看到「上傳完成」

8
觀察結果

看 Arduino 有沒有按你寫的方式動，必要時開序列監視器

🪄 自動完成

輸入函數名稱前 2-3 個字，IDE 會跳出建議 — 按 Tab 鍵自動補完！

🎨 語法高亮

不同顏色代表不同意思：黃色=關鍵字、藍色=字串、灰色=註解

❌ 上傳失敗？

檢查：USB 線、開發板選對、序列埠選對。或者拔 USB 重插

❌ 編譯錯誤？

仔細看紅字訊息，最常見：少分號 ; 或括號 { } 沒配對

📚 範例程式寶庫

檔案 → 範例 → 內建超多範例可以直接修改學習！

🔍 序列監視器卡卡？

看右下角「鮑率」要跟程式裡 Serial.begin(9600) 一樣
