3 步驟，準備好開始寫程式 🤖

下載 Arduino IDE → 接上開發板 → 上傳第一個程式。20 分鐘讓 LED 燈在你的指令下閃爍！

🎒 開始前，先準備這 4 樣東西

① 電腦

Windows / Mac / Linux 都行

② USB 線

Type-B 接頭（粗粗方方）

③ Arduino 板

Uno R3 / Nano / Mega 都可

④ Arduino IDE

下方有下載連結

🛠️ 安裝設定 5 步驟

跟著做就行，每步都附小提示！

1

💾 安裝 Arduino IDE

下載完成後，雙擊安裝檔啟動安裝程式。

  • 同意授權條款
  • 用預設安裝路徑就好（不用改）
  • 等待安裝完成（約 2-5 分鐘）
⚠️ Windows 會問要不要安裝 驅動程式 → 一律選「是」！
2

🔌 把 Arduino 接上電腦

拿 USB 線：方形那端接 Arduino，扁平那端接電腦。

✅ L 燈閃爍 + 綠燈亮 = 連接成功！（出廠就燒了 Blink 範例）
3

⚙️ 啟動 Arduino IDE

桌面找 Arduino 圖示，雙擊打開。

  • 第一次開可能要等 1-2 分鐘（IDE 在下載必要套件）
  • 看到深藍色程式編輯區 = 成功啟動
4

🎯 選對開發板和序列埠

左上角下拉選單兩個都要選：

  • Board（開發板）：通常選 Arduino Uno
  • Port（序列埠）：Windows 是 COM3 / COM4、Mac 是 /dev/cu.usbmodem...
🔍 找不到 Port？檢查 USB 線、換個 USB 孔、或重裝驅動程式
5

✨ 上傳第一個程式：Blink

選 檔案 → 範例 → 01.Basics → Blink，然後按上方「➡️ 上傳」按鈕。

  • 等 5-10 秒（畫面下方會跑進度條）
  • 看到「上傳完成」就大功告成！
🎉 Arduino 的 L 燈每秒閃一下 = 你的第一個程式跑起來了！

❓ 常見問題（卡住了？看這裡）

電腦找不到 Arduino，沒有 Port 可選怎麼辦？
  • 確認 USB 線插穩（兩端都要）
  • 試試換另一條 USB 線 — 有些便宜線只能充電不能傳資料
  • 換個 USB 孔（電腦背面通常比較穩）
  • 重新安裝 Arduino 驅動程式（IDE 安裝時的那個）
上傳程式失敗，跳紅字錯誤訊息？
  • 檢查 Board 和 Port 都選對了嗎？
  • 另一個程式可能正在用序列埠（關掉序列監視器）
  • 如果是「avrdude error」→ 多試 1-2 次
  • 還是不行 → 拔 USB、重插、重啟 IDE
L 燈沒閃爍，是不是壞了？
  • 確認 Arduino 的綠色電源 LED 有亮 — 沒亮表示沒供電
  • 嘗試上傳一次 Blink 範例（檔案 → 範例 → 01.Basics → Blink）
  • 還是不閃 → 換 USB 線試試
Mac 出現「無法打開因為它來自未知開發者」？
到「系統偏好設定 → 安全性與隱私 → 一般」找到 Arduino 那行，按「強制打開」。或對著 Arduino 圖示 按住 Ctrl 點擊 → 打開。

🎉 安裝完成！下一步呢？

你已經有開發環境了，可以開始寫自己的程式。建議先看「IDE 使用教學」熟悉介面，再到「接腳原理」認識 Arduino 板上每個腳位。
